# AI-Peer-Review-tracker
Companion to "AI for Peer Review: the Good, the Bad and a Path Forward" (Islamaj, Comeau, Yeganova, Tian, Kim, Lemberger, Gashteovski and Lu). This page tracks empirical qualitative studies on AI use in scientific peer review, mapped where relevant to the three-tier AI-in-Peer-Review adoption framework.
